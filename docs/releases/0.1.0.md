# Toad 0.1.0

First release in the Toad version series. Historical TurboScript release assets
and SDK packages have been retired at the repository owner's request.

- Native headers, C symbols, CMake targets and plugin identities use Toad:
  `<toad/script.h>`, `toad_script_*`, `Toad::Script`, and `toad.*`.
  Update and rebuild existing hosts and plugins together; old native names are
  incompatible. Script files retain the `.tbs` extension.
- Consume the published split SDKs: vcpkg-cache 0.1.3, SaltsBase 0.1.8,
  CMeta 0.1.7, SaltsUtils 0.1.4, CNet 0.1.12, and CHttp 0.1.0.
- Restore Lemon and re2c from the versioned vcpkg-cache host packages. Use MIR
  from the selected preinstalled triplet. QuickJS/Lua adapters are not used.
- Remove fuzzy/TRE and Cron integration. Timers retain `after`, `every`,
  `cancel`, and `status`; `timer.cron` is no longer available. TurboDB remains
  inactive and is not restored or required by this release.
- Repair fin/TA/time-series build ownership, MIR merge and rename errors,
  managed-value helper declarations, and mutable-container access lifetimes.
- Stage Windows net plugin runtime dependencies beside the plugin without
  broadening CMeta's restricted DLL search policy.

Assets include profile-specific SDK archives, `Toad.Native.0.1.0.nupkg`, and
`SHA256SUMS`. Each archive records its exact source commit, upstream versions,
profile and producer workflow run in `toad-sdk-manifest.json`.

Windows LLVM-MinGW x64, Linux Clang x64 and macOS Clang arm64 use the complete
formal CTest suites. Android arm64-v8a qualification covers cross-build,
installation and ELF load-segment alignment; it does not establish device
runtime behavior. Review the linked producer workflow for the actual results.

The NuGet package contains SDKs and native plugins, without the CLI. Restore
matching upstream SDKs before consuming the exported CMake targets; SDK build
instructions and dependency inputs are documented in the repository README.
