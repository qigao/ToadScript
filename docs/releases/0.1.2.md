# Toad 0.1.2

This release fixes concurrent Host context initialization and adds opt-in
explicit call admission for embedded computation.

- Builtin Script modules register once per runtime instead of being appended
  for every context. Engine registry registration, sorting and lookup share a
  mutex; reflected entries are copied before the lock is released.
- `TOAD_SCRIPT_MODULE_EXPLICIT_CALLS` closes a module's callable set over named
  script functions, list construction and explicitly registered host callbacks.
  Ambient builtins, imports, dynamic invocation, callable shadowing and
  unsupported dynamic forms fail before MIR lowering. Default module behavior
  and the options layout remain unchanged.
- Formal regressions exercise eight simultaneous context owners, interpreter
  and JIT execution, and capability rejection before execution.

Scripts and callbacks remain trusted host code. Explicit admission does not
provide process isolation or a hard execution deadline.

The release uses Base 0.1.8, CMeta 0.1.7, Utils 0.1.4, CNet 0.1.12,
CHttp 0.1.0 and vcpkg-cache 0.1.3. SDK manifests and SHA256SUMS accompany the
Windows LLVM-MinGW x64, Linux Clang x64, macOS Clang arm64 and Android arm64
artifacts. Android qualification is cross-build/install and ELF alignment;
it does not imply device execution.

Version 0.1.1 did not complete GitHub Release publication because its release
notes were missing. Its partial NuGet publication is retired; consumers should
use this qualified release. Existing source tags and Toad 0.1.0 are preserved.
